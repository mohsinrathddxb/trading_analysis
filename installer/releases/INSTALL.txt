Installation:
  1. Download the setup EXE through Git LFS or from the GitHub file page.
  2. Run the setup file on a 64-bit Windows computer.
  3. Start Telegram Strike Monitor from the desktop or Start menu shortcut.
  4. Complete the first-run Telegram setup and one-time phone/code authorization.

The installer includes the self-contained WPF application, portable Python
runtime, Python packages, and English Tesseract OCR runtime. It does not
include Telegram credentials, session files, market databases, downloaded
images, or generated reports.
